# Netflix Content Success Analytics Engine

## Project Overview

This project develops a **Netflix Content Success Analytics Engine** using machine learning and data analytics techniques.

The system analyzes Netflix content and generates model results, feature importance information, analytical reports, and content-level insights.

## Objectives

* Prepare the Netflix analytics dataset.
* Perform feature engineering.
* Build a machine learning model for content success analysis.
* Evaluate model performance.
* Identify important features.
* Generate analytical reports.
* Analyze Netflix content by type and rating.
* Save the trained model and preprocessing components.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Joblib

## Methodology

### 1. Data Preparation

The Netflix dataset is processed and prepared for analytics and machine learning.

### 2. Feature Engineering

Relevant Netflix content features are prepared and transformed for use in the machine learning model.

### 3. Content Success Analysis

A success-related target is created using the available Netflix dataset information and used for machine learning analysis.

**Note:** The success target used in this project is an analytical proxy based on the available dataset features. It does not represent actual Netflix viewer popularity or official Netflix success data.

### 4. Model Training

Machine learning models are trained using the prepared Netflix data.

### 5. Model Evaluation

The trained model is evaluated using classification performance metrics.

### 6. Feature Importance

Feature importance is calculated to understand which features contribute to the model's predictions.

### 7. Analytics

Additional analytics are generated for:

* Content type
* Audience rating
* Overall content analytics
* Top analytics content

## Generated Files

The following files are generated:

* `netflix_rating_analytics.csv`
* `netflix_content_success_model.pkl`
* `netflix_content_analytics_preprocessor.pkl`

## Results

The analytics engine provides machine learning-based analysis of Netflix content and generates multiple analytical outputs, including model results, feature importance, content type analysis, rating analysis, and content reports.

## Conclusion

This project demonstrates an end-to-end **machine learning and analytics workflow** for Netflix content analysis, covering data preparation, feature engineering, model training, evaluation, feature importance, and analytical reporting.
